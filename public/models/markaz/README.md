Diambil 14 November 2026 melalui tautan unduh resmi Kenney.
Perubahan: tekstur PNG eksternal ditanam ke GLB; geometri dan animasi asli dipertahankan.
Reproduksi: ekstrak paket resmi ke direktori bernama seperti slug paket, lalu jalankan
`python3 scripts/prepare-markaz-assets.py /path/to/extracted-packs` dari proyek.

Warung pilihan pengguna belum dibundel:

Pembuat: alterego.visual. CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
API resmi menyatakan dapat diunduh, tetapi endpoint unduhan memerlukan autentikasi.
Menunggu berkas unduhan resmi dari pengguna; tidak memakai model pengganti.
Saat berkas tersedia: tanam tekstur, periksa ukuran/vertex, tambahkan kredit pembuat
beserta sumber dan perubahan pada tampilan peta sebelum menerbitkannya.
